# Funimate Growth Audit

**Live → https://eddieatadapty.github.io/funimate-flow-rebuild/**

Five ideas to turn more Funimate users into subscribers, each built into a clickable version of Funimate's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask what they want to make, then build the path around it | +10–20% CR to purchase |
| 02 | Clear the three system prompts off the way to the paywall | +10–15% CR to purchase |
| 03 | Let sign-up wait until after the purchase | +10–17% ARPU · CR +5–10% |
| 04 | Show 672K ratings where they decide | +10–15% CR to purchase |
| 05 | Give the people who close the paywall a smaller yes | +10–15% ARPU |

Every price, rating and feature comes from Funimate's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Funimate. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
